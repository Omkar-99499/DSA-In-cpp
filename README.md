# Pointer Basic Concepts

## Problem Statement

Develop a C program to demonstrate the basic concepts of pointers, including pointer declaration, initialization, address operator (&), and dereference operator (*).

## Algorithm

1. Start.
2. Declare an integer variable `num` and a pointer `ptr`.
3. Accept an integer number from the user.
4. Store the address of `num` in `ptr`.
5. Display the value of `num`.
6. Display the address of `num`.
7. Display the address stored in `ptr`.
8. Display the value accessed through `ptr`.
9. Stop.
